# Site IMAVAITA

Site vitrine et catalogue de location de véhicules au Togo. Réservations via WhatsApp.

```bash
npm install
npm run dev      # http://localhost:4321 (les fiches « brouillon » sont visibles)
npm run build    # vérifie les types puis génère dist/
```

- Administration du catalogue : `/admin/` (Sveltia CMS), voir [docs/GUIDE_ADMIN.md](docs/GUIDE_ADMIN.md).
- Architecture, déploiement et décisions : [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- Brief client : [docs/BRIEF.md](docs/BRIEF.md). Règles pour Claude : [CLAUDE.md](CLAUDE.md).
